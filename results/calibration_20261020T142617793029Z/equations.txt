Dynamics
--------

Compact form
~~~~~~~~~~~~
Bin Transitions:
susceptble_to_latent (S -> E):
  S_y65 -> E_y65: beta * S_y65 * (IR + IH) / total
  S_o65_nv -> E_o65_nv: beta * S_o65_nv * (IR + IH) / total
  S_o65_v -> E_o65_v: beta * S_o65_v * (IR + IH) / total

exposed_to_infectious (E -> IR):
  E_y65 -> IR_y65: (1 - p_h_y) * t_latency * E_y65
  E_o65_nv -> IR_o65_nv: (1 - p_h_nv) * t_latency * E_o65_nv
  E_o65_v -> IR_o65_v: (1 - p_h_v) * t_latency * E_o65_v

exposed_to_hospital_bound_infectious (E -> IH):
  E_y65 -> IH_y65: p_h_y * t_latency * E_y65
  E_o65_nv -> IH_o65_nv: p_h_nv * t_latency * E_o65_nv
  E_o65_v -> IH_o65_v: p_h_v * t_latency * E_o65_v

infectious_to_recovered (IR -> R):
  IR_y65 -> R_y65: t_recovery * IR_y65
  IR_o65_nv -> R_o65_nv: t_recovery * IR_o65_nv
  IR_o65_v -> R_o65_v: t_recovery * IR_o65_v

hospital_bound_infectious_to_hospitalized (IH -> H):
  IH_y65 -> H_y65: t_hospitalization_nv * IH_y65
  IH_o65_nv -> H_o65_nv: t_hospitalization_nv * IH_o65_nv
  IH_o65_v -> H_o65_v: t_hospitalization_v * IH_o65_v

hospitalized_to_recovered (H -> R):
  H_y65 -> R_y65: t_hospitalization_recovery_nv * H_y65
  H_o65_nv -> R_o65_nv: t_hospitalization_recovery_nv * H_o65_nv
  H_o65_v -> R_o65_v: t_hospitalization_recovery_v * H_o65_v

vaccination_S (S -> S):
  S_o65_nv -> S_o65_v: doses * S_o65_nv / (S_o65_nv + R_o65_nv)

vaccination_R (R -> R):
  R_o65_nv -> R_o65_v: doses * R_o65_nv / (S_o65_nv + R_o65_nv)

births (none -> S):
  none -> S_y65: births

S_y65_to_S_o65 (S -> S):
  S_y65 -> S_o65_nv: aging * S_y65

E_y65_to_E_o65 (E -> E):
  E_y65 -> E_o65_nv: aging * E_y65

IR_y65_to_IR_o65 (IR -> IR):
  IR_y65 -> IR_o65_nv: aging * IR_y65

IH_y65_to_IH_o65 (IH -> IH):
  IH_y65 -> IH_o65_nv: aging * IH_y65

R_y65_to_R_o65 (R -> R):
  R_y65 -> R_o65_nv: aging * R_y65

S_death (S -> none):
  S_y65 -> none: death_y65 * S_y65
  S_o65_nv -> none: death_o65 * S_o65_nv
  S_o65_v -> none: death_o65 * S_o65_v

E_death (E -> none):
  E_y65 -> none: death_y65 * E_y65
  E_o65_nv -> none: death_o65 * E_o65_nv
  E_o65_v -> none: death_o65 * E_o65_v

IR_death (IR -> none):
  IR_y65 -> none: death_y65 * IR_y65
  IR_o65_nv -> none: death_o65 * IR_o65_nv
  IR_o65_v -> none: death_o65 * IR_o65_v

IH_death (IH -> none):
  IH_y65 -> none: death_y65 * IH_y65
  IH_o65_nv -> none: death_o65 * IH_o65_nv
  IH_o65_v -> none: death_o65 * IH_o65_v

H_death (H -> none):
  H_y65 -> none: death_y65 * H_y65
  H_o65_nv -> none: death_o65 * H_o65_nv
  H_o65_v -> none: death_o65 * H_o65_v

R_death (R -> none):
  R_y65 -> none: death_y65 * R_y65
  R_o65_nv -> none: death_o65 * R_o65_nv
  R_o65_v -> none: death_o65 * R_o65_v

Total System: 18 coupled equations (6 bins × 2 age × 2 vaccination)

Expanded form
~~~~~~~~~~~~~
[S_y65(t+Dt) - S_y65(t)] / Dt = - (beta * S_y65 * (IR + IH) / total) + (births) - (aging * S_y65) - (death_y65 * S_y65)
[S_o65_nv(t+Dt) - S_o65_nv(t)] / Dt = - (beta * S_o65_nv * (IR + IH) / total) - (doses * S_o65_nv / (S_o65_nv + R_o65_nv)) + (aging * S_y65) - (death_o65 * S_o65_nv)
[S_o65_v(t+Dt) - S_o65_v(t)] / Dt = - (beta * S_o65_v * (IR + IH) / total) + (doses * S_o65_nv / (S_o65_nv + R_o65_nv)) - (death_o65 * S_o65_v)
[E_y65(t+Dt) - E_y65(t)] / Dt = (beta * S_y65 * (IR + IH) / total) - (t_latency * E_y65) - (aging * E_y65) - (death_y65 * E_y65)
[E_o65_nv(t+Dt) - E_o65_nv(t)] / Dt = (beta * S_o65_nv * (IR + IH) / total) - (t_latency * E_o65_nv) + (aging * E_y65) - (death_o65 * E_o65_nv)
[E_o65_v(t+Dt) - E_o65_v(t)] / Dt = (beta * S_o65_v * (IR + IH) / total) - (t_latency * E_o65_v) - (death_o65 * E_o65_v)
[IR_y65(t+Dt) - IR_y65(t)] / Dt = ((1 - p_h_y) * t_latency * E_y65) - (t_recovery * IR_y65) - (aging * IR_y65) - (death_y65 * IR_y65)
[IR_o65_nv(t+Dt) - IR_o65_nv(t)] / Dt = ((1 - p_h_nv) * t_latency * E_o65_nv) - (t_recovery * IR_o65_nv) + (aging * IR_y65) - (death_o65 * IR_o65_nv)
[IR_o65_v(t+Dt) - IR_o65_v(t)] / Dt = ((1 - p_h_v) * t_latency * E_o65_v) - (t_recovery * IR_o65_v) - (death_o65 * IR_o65_v)
[IH_y65(t+Dt) - IH_y65(t)] / Dt = (p_h_y * t_latency * E_y65) - (t_hospitalization_nv * IH_y65) - (aging * IH_y65) - (death_y65 * IH_y65)
[IH_o65_nv(t+Dt) - IH_o65_nv(t)] / Dt = (p_h_nv * t_latency * E_o65_nv) - (t_hospitalization_nv * IH_o65_nv) + (aging * IH_y65) - (death_o65 * IH_o65_nv)
[IH_o65_v(t+Dt) - IH_o65_v(t)] / Dt = (p_h_v * t_latency * E_o65_v) - (t_hospitalization_v * IH_o65_v) - (death_o65 * IH_o65_v)
[H_y65(t+Dt) - H_y65(t)] / Dt = (t_hospitalization_nv * IH_y65) - (t_hospitalization_recovery_nv * H_y65) - (death_y65 * H_y65)
[H_o65_nv(t+Dt) - H_o65_nv(t)] / Dt = (t_hospitalization_nv * IH_o65_nv) - (t_hospitalization_recovery_nv * H_o65_nv) - (death_o65 * H_o65_nv)
[H_o65_v(t+Dt) - H_o65_v(t)] / Dt = (t_hospitalization_v * IH_o65_v) - (t_hospitalization_recovery_v * H_o65_v) - (death_o65 * H_o65_v)
[R_y65(t+Dt) - R_y65(t)] / Dt = (t_recovery * IR_y65) + (t_hospitalization_recovery_nv * H_y65) - (aging * R_y65) - (death_y65 * R_y65)
[R_o65_nv(t+Dt) - R_o65_nv(t)] / Dt = (t_recovery * IR_o65_nv) + (t_hospitalization_recovery_nv * H_o65_nv) - (doses * R_o65_nv / (S_o65_nv + R_o65_nv)) + (aging * R_y65) - (death_o65 * R_o65_nv)
[R_o65_v(t+Dt) - R_o65_v(t)] / Dt = (t_recovery * IR_o65_v) + (t_hospitalization_recovery_v * H_o65_v) + (doses * R_o65_nv / (S_o65_nv + R_o65_nv)) - (death_o65 * R_o65_v)

Schedule
--------

Each step applies every flow once, computed from the state at the start of the step: X(n + 1) = X(n) + sum of the flows. The impulses of a step act first, and its flows run from the new state.
